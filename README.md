# AI Job Searcher - NVIDIA/Nemotron VL via OpenRouter

A Python project that searches for worldwide, remote-friendly job listings matching strict criteria and outputs results as valid JSON.

## 🚀 What It Does

This project uses the **NVIDIA/Nemotron-3.5-super-vl** model (via OpenRouter API) to search for AI/ML positions that match your strict filters. The output is **valid JSON** containing:

### Required Fields for Each Job:
- `source` - e.g., "linkedin", "indeed", "remotejobs.io"
- `source_id` - Unique ID from the source or URL hash
- `title` - Job title
- `company` - Company name
- `location` - Geographic location (must be Remote/USA/Germany/UK/Australia)
- `salary_usd` - Annual salary in USD (≥ $80k required, or $60k-$80k for remote only)
- `description` - Short job excerpt (≤ 200 chars)
- `url` - Job posting URL
- `posted_at` - ISO-8601 timestamp (must be within last 7 days)
- `seniority` - "Senior", "Lead", or "Principal" (or null for gigs)
- `skill_score` - Bonus field (0-100) estimating skill match

## 🔍 Strict Filter Rules Applied:

1. **Remote-only** jobs OR location in [Remote, USA, Germany, United Kingdom, Australia]
2. **Salary ≥ $80k** (or $60k-$80k if remote only)
3. **Seniority**: Senior, Lead, Principal (or null for gigs/micro-tasks)
4. **Industry**: Must contain AI/ML, FinTech, SaaS, or Cloud Computing
5. **Keywords**: ALL must be present - Kubernetes, PyTorch, CI/CD, AND (AWS OR GCP OR Azure)
6. **Exclude**: RecruiterCo, TempStaff, StaffingSolutions
7. **Gigs**: Hourly pay ≥ $15/hr OR project value ≥ $200
8. **Recency**: Posted within last 7 days only

## 🛠️ Installation & Setup

### Step 1: Install Python Dependencies

```bash
pip install -r requirements.txt
```

Required packages:
- `python-dotenv>=1.0.0` - Load .env files
- `requests>=2.31.0` - HTTP requests (for real API integration)
- `aiohttp>=3.9.0` - Async HTTP client

### Step 2: Configure Environment Variables

Copy your keys from `Keys.txt` to `.env`:

```ini
OPENROUTER_API_KEY=sk-or-v1-...your-key-here
NVIDIA_MODEL=nvidia/nemotron-3.5-super-vl
```

**IMPORTANT**: Your API key is now stored securely in `.env`. Never commit this file to version control!

## 💡 Feature: skill_score Calculation

For each qualifying job, a **skill_score (0-100)** is calculated based on:
- How many of your key skills (from `profile.yaml`) are mentioned
- Rarity among similar jobs
- Number of unique skills matched

Higher score = better fit for learning new tools or deepening expertise.
